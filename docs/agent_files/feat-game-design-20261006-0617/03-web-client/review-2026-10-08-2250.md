## Must-fix findings

1. **P2 — Mirrored model transforms reverse face orientation.** `apps/web/src/render/model.ts:38` bakes a node transform with a negative determinant into geometry without reversing triangle vertex ordering across all vertex attributes. A valid mirrored, single-sided GLB can therefore have its exterior culled. Preserve the model's face orientation when baking mirrored transforms; verify single-sided exterior visibility and matching attribute ordering.
2. **P2 — Non-default texture coordinate channels are discarded.** `apps/web/src/render/model.ts:48`–51 retains only `uv` during model conversion. GLTF textures using `texCoord: 1` or Three `uv1`/`uv2`/`uv3` lose the required attributes while cloned materials retain their texture channel selection. Valid textured models consequently render with wrong mapping. Preserve all referenced UV channels and verify textured multi-channel GLB rendering.
3. **P2 — Source cache is evicted before restart/transition acquisition.** `apps/web/src/manifest/assets.ts:34` defaults `maxIdle` to zero, and app state clears the current level before acquiring the next one. Every successfully released source is evicted, so restarting refetches/decodes assets and may fail offline. This violates the planned cache-survives-level-change/restart contract. Retain a bounded successful source cache across releases while preserving explicit final disposal; verify restart reuse, offline reuse and cleanup.
4. **P2 — Valid drawing preview does not follow the colourblind palette.** `apps/web/src/input/index.ts:107` always picks the default valid-preview colour. `apps/web/src/app/runtime.ts:103`–110 propagates settings to towers, troops, lines and effects, while input refresh receives no palette update. BugHunter confirmed a valid preview remains `#367BE8` after colourblind settings while the actual route uses `#0072B2`. Propagate the active palette to preview rendering and verify live settings changes and initial colourblind state.
