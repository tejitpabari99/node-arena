# Task 8 — Replay record/playback

`createReplayRecorder(compiledLevel, seed, metadata)` owns a Sim and wraps its public
API. `metadata` is an explicit `ReplayMetadata` projection of authoritative content.json
rules/schema/content versions. No runtime content imports or copied version defaults.
`record()` returns a detached JSON-serializable `ReplayRecord`.

`playReplay({metadata, level}, record)` supports compiled-level callers.
`playReplay({metadata, resolveLevel: id => compileLevel(loadedContent, id)}, record)`
supports tools: compilation stays outside sim's type-only content boundary. No bots
are instantiated or consulted. Recorder, source, record, result and metadata types are
exported; TICK_RATE remains exported.

## Contract clarifications

- Additive required `finalTick` disambiguates empty and manually stopped recordings.
  Final hash and outcome are compared at exactly that tick, including incomplete games.
- Submission tick is the current sim tick, before the next step increments it. Array
  order retains original submission order, including rejected commands. Playback
  feeds that order to the same canonicalizing command applier.
- JSON-compatible malformed command shapes are preserved and rejected by the sim.
  Lossy/non-JSON submissions (undefined, cycles, non-finite values) throw before any
  step or history mutation. Caller, rejection-event, and exported-record mutations
  cannot mutate recorded history.
- Header mismatches and malformed records throw `Invalid or incompatible replay`;
  disagreements return `{ok:false, sim, divergingTick}`. Divergence is the first
  observable checkpoint tick, or finalTick. The 20-tick record cannot identify an
  earlier exact state mismatch between checkpoints.
- Checkpoints must occur exactly every TICK_RATE ticks in ascending order. Submission
  ticks must be ascending and less than finalTick. Postgame recorder steps are inert;
  playback refuses ticks or commands extending beyond gameover.
- Seed is an explicit uint32; a changed valid seed is detected by state hashes.
