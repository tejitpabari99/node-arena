## Arithmetic contract / deviations
Engine progress is milli*20. Interval endpoints use engine progress; world coordinates/radii/pad use milli. Rational lane points preserve engine length exactly. Integer projection identity superseded by exposed rational factors because floor-length vectors are not unit vectors. Q20 yaw is exact against represented axes; a compact 32-step integer CORDIC supports every compiled milli-degree value with error <1 Q20 unit per component. Positive content yaw rotates +x toward -z (Unity/Three +Y).

`laneIntervals` samples integer progress; sub-progress continuous overlaps may produce no samples. `corridorOverlaps` separately handles continuous strict overlap. Corridor normal uses the engine floor-length normalization, explicitly recorded in PRD. All-stage tower/crossing caches must be created cold; tick-time draw/stage hooks must not invoke BigInt geometry.
