## Observations (observed)
- Camera: fixed top-down-ish 3/4 tilt (~55-60 deg), portrait phone ~465x1030, no rotation; buildings seen from front-above, play area centre, decorative scenery bands top and bottom.
- Team colours: blue = player, red, green, yellow enemy teams, gray = neutral. Building roof colour = owner; stacked floors grow with count (5 -> 1 floor, 30+ -> 4-5 floors; 45/52 very tall). Round coloured number badge on roof with small dots (dots = level tier: 1-3 dots).
- Number labels: white bold rounded font on coloured roof badge, tiny; factories show up-arrow + number (e.g. up10, up30), 'Max' text when capped.
- Tower range: pagoda/watch tower (gray pagoda roof, stilts) shown with translucent white circle = range; tower shoots projectile at passing soldiers; captured via lanes (number on tower = HP/garrison).
- Obstacles: pine tree lines (canyon levels), ice-block walls + wooden fences (snow 26-31), wooden crate walls + mines (black/red discs) (desert 41-51); mines tutorial at 35.
- Environment: canyon/desert-plateau grass 1-20; SNOW starts at 21 (ice floor, igloo, campfire); desert mine/railway biome from 41; jungle temple from 61.
- HUD: pre-start: gear icon top-left, LEVEL N text, coin pill top-right, green PLAY bottom. In play: undo arrow top-left, segmented pill bar with LEVEL N in centre (blue/red/green/yellow segments = share of forces), no coins; L50 shows coin total + 250-coin rocket button bottom-left. Pause icon centre in L61.
- Lanes: translucent coloured bands between buildings (blue for player, orange-red enemy, green, yellow) with small dotted tint; units are tiny soldiers walking along lanes, tanks from tank factories; red hit particles on arrival.
- Victory screen: ribbon, mascot, NEW REGION %, +coins, confetti.
