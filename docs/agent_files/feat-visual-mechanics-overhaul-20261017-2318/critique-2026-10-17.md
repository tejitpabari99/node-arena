# Critique — v1.1 plan (brief, README, 5 PRDs, 5 TASKS)

### Blocking Issues
B1. **Tower body colour contradicts refs + calibration.** Brief/SP03 R7/T4/V05/M11 say whole tower team-painted (M11 ≥45% tower pixels within ±25° team hue). In towerwar_01/03/06/yt1 towers are white/grey stone bodies with team-coloured roof cap + team trim bands (REFERENCE.md agrees). Whole-tower is City Takeover. Fix: brief + SP03 R7/T4 + V05 → white/grey body, team roof cap, team trim bands/ring per floor, neutral all-grey; M11 → team-hue share of roof+trim; run M07–M11 on towerwar_01/yt1 crops in calibration and require pass.
B2. **Pixel metrics uncalibrated / unpassable.** SP01 M10 "HSL s .3–.8, l>.55, hue 20–50": PRD's own sand #FFE1B3 is HSL s≈1.0 (HSV s≈0.30) → fails/edge; rock #BC5439 hue 12° outside. M10 measures outer 20% L/R but in refs border is top/bottom, sides are grass (only works under landscape assumption). M09 hue 70–150 straddles sampled grass hue ≈75°; shaded/yellow-green <70. Fix: specify colour space; calibrate M07–M11 thresholds on ref crops + a hand-built landscape mock.
B3. **Self-scoring can't catch drift.** Same agent edits, composes, views and scores against anchors like "= 01"/"indistinguishable"; calibration (ref scoring ≥8 vs itself) is near-tautological. Probe metrics (countOnRoof, floors, slotDots, hasCard, splitScreen) are self-reported by the renderer under test. Fix: before any score ≥8 the agent must log ≥3 concrete observable differences vs the ref (proportion, hue, density, stripe count); add one objective pixel check per item (colour-histogram distance on matched crops; probe-independent roof-decal pixel visibility); require a second, blind scorer agent per iteration.
B4. **SP02 may not fix the churn the user sees.** packages/sim/src/commands.ts:12 LineCut has reason:'slots'; rules §159 auto-cut the newest line when garrison ≤ slot threshold (extraSlotAbove 10/30). Sending lowers garrison → bot near 10 loses a line to slot enforcement then redraws = churn without any bot CutLine. SP02 R9 counts only bot commands; redrawBlock only for bot-cut pairs. Fix: churn tool counts LineCut events by reason (player/slots/captured/replaced) and reports slot-cuts/min; redraw block applies to slot-cut pairs too; bot guard against drawing a line on a slot the garrison is within a margin of losing. No GAME_RULES edit.
B5. **SP03 T5 exit depends on T6.** T5 gates M03 (no cards), M02, V07 but label cards are deleted in T6 → T5 burns 12 iterations → Blocked-visual. Fix: swap T5/T6 or have T5 hide cards when roof decal exists.
