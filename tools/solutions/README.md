# Band-four solution replays

Store a standalone `ReplayRecord` as `<levelId>.replay.json`, generated by `runMatch` with the authoritative content metadata and a stamped human-seat script. Commit it before running `validate:levels`. The gate verifies replay playback for the exact compiled level, then runs the human commands against the current authored bots and compares the winning outcome, final tick and hash.

Solutions apply only when a band-four level falls below its K−1 reference wins. Changed simulation identity or incompatible replay metadata requires regenerating the record. This directory contains no campaign solutions until authored levels need them.
