## Running

Start this worktree's test build preview on port 4173, then run `pnpm kane:replay`.
The wrapper can also start it with `pnpm kane:replay -- --serve`.
Kane authentication and Playwright Chromium are required. Keep the test and
`output-panel_draw_cut/` together; replay copies both to a temporary directory.

Authoring command used:

```sh
KANE_CLI_USER_AGENT=codex \
KANE_CLI_CHROME_PATH=/root/.cache/ms-playwright/chromium-1248/chrome-linux64/chrome \
kane-cli testmd run tools/kane/tests/panel_draw_cut_test.md \
  --headless --agent --assertion-mode dom --timeout 240
```

Both assertions recorded DOM extraction (`innerText` / `textContent`) and text
comparison. Kane names that analyzer `textual_visual` internally; the recorded
checks contain DOM JavaScript and role/text locators. No image comparison is used.
The recording contains the CLI's generated click code, including its coordinate
fallback; this was generated by Kane, not hand-written Playwright.

## Regression evidence and limitation

The negative replay served an isolated copy of `apps/web/dist-test` on the same
private port. A MutationObserver changed only the rendered A → C button's `ready`
text to `broken`. Raw CDP confirmed `A → C · broken · C: grey 15`. No application
source or saved recording was edited. The normal worktree preview was restored.

The file failed with `assertion_failed: @ step 3` in its second root step and
`test_md_done.overall_status=failed`; adaptive healing stayed off and no authoring
occurred. **The task's requested literal `action_failed` reason was not observed.**
Kane's generated click contains a coordinate fallback, so changing text does not
necessarily fail the click. Its first DOM read also fell back to the other ready
button; the final active assertion caught the regression. This narrower first
check is a recorded CLI limitation, not evidence that the wrong pair is acceptable.

SHA-256 hashes of the test and all cache files were identical before and after
both replays. `git status --short` was identical before/after the positive replay
(only pre-existing orchestrator TASKS bookkeeping and these untracked test files).

committed output. The output contains the private tenant/test IDs allowed by R8;
